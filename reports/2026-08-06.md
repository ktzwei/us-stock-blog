# 美股小白观察报告 · 2026.08.06

## 一、今日最热方向

### 🔥 Google 大地震：Jeff Dean 离职 + 组织大换血

今天整个美股圈都在讨论一件事——**Google 的灵魂人物 Jeff Dean 离职了**。

这位在谷歌干了 27 年、级别 L11（全公司几十万人里凤毛麟角）的传奇工程师，宣布创立新公司 Discovery Loop。而在此之前，AlphaFold 诺奖得主 John Jumper 跳去了 Anthropic，Transformer 论文作者 Noam Shazeer 去了 OpenAI。

Google 的回应是立刻宣布组织架构调整：
- **Demis Hassabis**（原 DeepMind CEO）卸任日常运营，转为 GDM 主席 + Alphabet 首席科学家
- **Koray Kavukcuoglu**（原 DeepMind CTO）升任 SVP，直接向劈柴汇报，全面负责 Gemini

**市场反应**：$GOOG 当日跌了约 5%。

但有意思的是——好几位博主都在讲「二阶思维」：这不一定是坏事。Google 之前山头林立、决策缓慢，现在 Hassabis 被「架空」去做战略、Koray 专注产品落地，长期看可能反而让 Gemini 加速。

### 🧠 AI 算力链：存储 + 光通信双线博弈

今天硬件赛道的信息密度极高，两条线同时在发酵：

**存储线**：
- $SNDK 财报后下跌，Jukan 发长文分析：毛利率见顶不一定是坏事，说明 SanDisk 没在压榨客户，而是走长期路线。只要 AI 超级周期继续、大厂 Capex 不停，存储公司应该从「周期股」被重估为「AI 基础设施」。
- 川沐实操：减了 SNXX/MUU/SK Hynix 一半仓位，等闪迪财报波动结束后集中到 MUU 和 SNXX。
- NVIDIA Rubin 的 SOCAMM2 配置被砍到 64GB——Jukan 解读为供应端瓶颈（内存厂商只能供 60-70%），不是需求问题。

**光通信线**：
- $AEVA 盘后暴涨 18%，原来是签了一个 CPO/NPO 光引擎合作，给某大 hyperscaler 供货，2027H2 部署。
- $VIAV 说 CPO 已经在产生收入了，12 月会加速。
- Roundhill 明天上线光学 ETF（LYTE），对标之前大火的 DRAM ETF。
- 对冲基金圈的博弈：很多人 long 存储 short 光通信，理由是「中国会 flooding the market with lasers」。

## 二、其他关注方向

### 📉 宏观：市场等两个关键信号

qinbafrank 的分析：美股连涨四天后回调很正常，现在市场在等两件事：

1. **美伊谈判**：霍尔木兹海峡能不能重新打开 → 油价回落 → 通胀担忧解除。这件事甚至比下周的 CPI 数据更重要。
2. **大非农**：昨晚 ADP 小非农远低于预期 → 明晚正式非农大概率也疲软 → 劳动力市场趋弱 → 加息担忧消除。

如果这两个剧本都兑现，市场情绪会明显回暖。AI 基本面没问题——这波财报季已经证明了商业化在加速，ROIC 已经开始能算出来了。

| 术语 | 解释 |
|------|------|
| **$GOOG** | Google 母公司 Alphabet 的股票代码 |
| **$SNDK** | SanDisk，闪存/存储公司，刚被分拆独立上市 |
| **$AEVA** | Aeva Technologies，激光雷达公司，现拓展光通信 |
| **$AAOI** | Applied Optoelectronics，光通信器件公司 |
| **$VIAV** | Viavi Solutions，光通信测试设备商 |
| **$MSFT / $PLTR / $NET** | 微软 / Palantir / Cloudflare，云和软件代表 |
| **CPO / NPO** | Co-Packaged Optics / Near-Packaged Optics，共封装光学——把光模块和芯片封装在一起，降低功耗，AI 数据中心的关键技术 |
| **SOCAMM2** | NVIDIA 的一种内存模组规格，用于 Rubin 平台 |
| **HBM / HBM4E** | High Bandwidth Memory，高带宽内存，AI 芯片的「高速缓存」 |
| **Capex** | Capital Expenditure，资本支出——科技巨头砸钱建数据中心 |
| **ADP / 大非农** | 美国就业数据。ADP 是私营机构统计（小非农），大非农是官方数据，后者更重要 |
| **ROIC** | Return on Invested Capital，投资回报率——判断 AI 投入是否划算的关键指标 |
| **LTA** | Long-Term Agreement，长期供货协议 |
| **12 英寸晶圆** | 300mm 硅晶圆，先进制程芯片的基础材料 |
| **BiCS10** | Kioxia 的第十代 3D NAND 闪存技术 |
| **NBM** | Non-Binding Memorandum，非约束性备协议——SanDisk 和客户的一种灵活供货模式 |
| **ELSFP** | 一种光模块封装标准 |
