## 一、今日最热方向

### 🚀 SpaceX 财报炸场：AI 算力投入暴增，云计算 1 年回本

SpaceX 最新财报数据全面超预期，引发博主圈集中讨论。**qinbafrank** 拆解得最为详尽：

- 营收 $78.14 亿，同比 +92%（预期 ~$69 亿）
- 净亏损缩窄至 $5.41 亿（每股 -$0.09），远优于预期的 -$0.26
- 调整后 EBITDA $35 亿，同比 +191%
- **资本支出暴增至 $183.7 亿**，其中 AI 相关约 $158.3 亿

> **Star** 补了一刀：SpaceX 云计算业务不到 1 年就能回本，"这是要开启印钞机模式了？" **qinbafrank** 进一步指出，SpaceX 自己的大模型 Grok 4 性能不错，卖 API 和 token 才是终极变现路径。

### 🚢 霍尔木兹海峡临时协议：航运瓶颈有望缓解

**qinbafrank** 援引 Axios 报道：美国、伊朗与阿曼接近达成 60 天临时协议，分航道通航（伊朗水域北侧进，阿曼水域南侧出），期间不收通行费，30 天内启动核协议谈判。若落地，全球航运和能源供应链的紧绷情绪将明显缓和。

### ⚡ HBM 减配罗生门：Rubin Ultra 12 层变 8 层？

**fin** 抛出尖锐观察：客户要求 NVIDIA $NVDA Rubin Ultra GPU 的 HBM 堆叠从 12 层砍到 8 层，"如果减配成为主流，下一代 token 效率还不如上一代，谁还买？" 他认为时机敏感——正处于明年 HBM 合约价谈判拉锯期，本质上是客户集体向 HBM 三大供应商施压降价。

**川沐** 则从另一个角度切入：DeepSeek 把百万 token 价格打到 0.02 人民币（远低于 1 美分），模型公司被迫集体降价 → 存储需求反而大增。他据此买入韩股 SK 海力士（156 万韩元成本），逻辑清晰。

### ☁️ AI 投资转向：从芯片到云和软件

**Star** 明确指出 $MSFT $PLTR $NET 大涨，"标志着 AI 投资从半导体开始转向云和软件"，并撰文梳理 Agent 时代的软件价值链。这个方向值得持续跟踪。

## 二、其他关注方向

## 六、专有名词小词典

| 术语/代码 | 解释 |
|-----------|------|
| **EBITDA** | 息税折旧摊销前利润，衡量公司经营赚钱能力的指标，比净利润更"纯净" |
| **CapEx** | 资本支出，公司花在买设备、建数据中心等长期资产上的钱 |
| **HBM** | 高带宽内存，GPU 用的超高速存储，AI 训练的关键零件。12hi = 12 层堆叠 |
| **HBF** | High-Bandwidth Flash，新出的开放标准，用 NAND Flash 做高带宽存储，替代方案 |
| **CoW** | Chip on Wafer，台积电的先进封装技术，把不同芯片"粘"在一起 |
| **UCIe** | 芯片间互连标准，让不同公司的芯片能"说同一种语言" |
| **FCC Covered List** | 美国联邦通信委员会的管制清单，上了这个名单的设备不能拿联邦补贴买 |
| **leap call** | 长期看涨期权，一般到期日在一年以上，杠杆押注股价上涨 |
