美股小白观察报告 · 2026.08.15

今天的市场主线非常清晰：存储芯片。从闪迪 $SNDK 的「疯狂长协」，到美国敦促苹果别买中国存储，再到 CPU 需求缺口的预判，几乎所有有分量的声音都指向同一条产业链。我们挨个拆开看。

一、今日最热方向

🧠 存储超级周期：闪迪 $SNDK 的「930 亿美金长协」

这是今天讨论密度最高的话题。核心信号来自闪迪投资者日给出的激进指引，而 @qinbafrank 把它拆得最透：

  • 闪迪已与 8 家大客户签下长期协议（NBM），协议期最长 5 年、加权平均 4 年。
  • 长协覆盖 2027、2028 年约 6 成产能。
  • 按地板价计算，所有已签长协的最低合同收入合计 930 亿美金，另有 165 亿美金保证金。
  • 折算下来，未来四年每年保底营收超 230 亿美金——而闪迪过去四个季度总营收才 200 亿美金。也就是说，光长协保底就快赶上现在一年的收入。
  • 定价是「固定 + 可变」混合模式，可变部分设了 floor（地板价）和 ceiling（顶价），管理层确认即使在 floor 价下毛利率仍约 80%（非 GAAP）。

@qinbafrank 还补了三个让股价继续走强的点：市场对长协的预期未必充分、回购/分红对股价的提振、以及 HBF 的预期。

配套信号也到位：

  • 美国政府敦促 $AAPL 不要购买中国存储芯片，$MU（美光）、$SKHY（SK 海力士）、三星「喜闻乐见」——这是 @aleabitoreddit（Serenity）的判断。
  • @xiaomustock（川沐）透露 $META 是继谷歌之后第二家支持并共同开发闪迪 HBF 标准的大公司。
  • 川沐自己也承认「赌性太强、越涨越想上杠杆」，但已在提醒自己落袋后开始定投 $SPY 和 $QQQ。

一句话：存储从「周期股」正在被市场重估成「长协锁定、毛利 80%」的类公用事业资产，这是本周最硬的叙事。

二、其他关注方向

⚡ CPU 需求缺口：下一个「存储式」行情？

@xiaomustock（川沐）判断 CPU 会复刻 2026 年存储的结构性缺口：

  • 现在 CPU 与 GPU 的配置需求比约 1:8，随着各大模型公司下场做 AI 代理（Agent），高端 CPU 需求会在 2–3 个季度内被爆拉到 1:1，即 8 倍需求。
  • 而高端 CPU 产能不可能在 2 个季度内提升 8 倍。
  • 他给出的时间窗口：最快今年年底、最慢 2027 Q1 看到 CPU 大幅提价，只剩 3–5 个月。
  • 佐证：英特尔 $INTC 这个季度高端 CPU 已在挤压低端产能；CEO 陈立武在播客透露英特尔正在研究 CPU 与存储堆叠封装的新型架构，以降低 AI 代理调用的延迟。

这是一条「左侧」逻辑，尚未兑现，但和存储的叙事一脉相承——都是「AI 代理普及 → 硬件结构性短缺」。

🔦 英伟达 CPO 交换机全面量产：光互连大事件

@qinbafrank 报道：英伟达 Spectrum-X Ethernet Photonics 进入全面量产，把硅光引擎与交换 ASIC 直接共封装（CPO，Co-Packaged Optics），取代传统可插拔光模块，专为超大规模 GPU 集群互联设计，覆盖数万到百万级 GPU。

这是光互连领域的分水岭。@LinQingV（Macro_Lin）的点评很接地气：「先把 Kyber 背板搞定，让胜宏去 500，去往 CPO 的路上不确定性还不少。」——提示这条链路上仍有工程不确定性。

@jukan05 补充：台媒 DigiTimes 报道英伟达下一代之后的 Feynman 平台将直接跳到 A16（台积电升级版 2nm），并提升 SoIC 3D 堆叠占比，预期搭配定制 HBM 与 CPO。

🥃 玻璃基板延期 + 无人机关税（@aleabitoreddit）

Serenity 提示两件事：

  1. 玻璃基板时间表又被推迟至少一个季度：三星电机、SKC 都因客户原型可靠性验证瓶颈而延后投产。
  2. 特朗普签署公告强化美国无人机供应链，对 UAS 相关部件加征 25%–100% 关税，利好 $UMAC、$ONDS、$RCAT 等美国本土无人机供应链（他声明自己没有持仓）。

💰 CSP（AI 云算力）定价权增强

@qinbafrank 从 CoreWeave 与 Nebius 财报提炼出趋势：需求仍远超可交付供给，瓶颈从「有没有客户」变成「什么时候能通电交付」。7 月各类 SKU 价格普遍上调约 25%，旧代 GPU 价格涨超 30%，短期紧急容量报价达每 MW 4000 万–5000 万美金。

三、值得关注的单点机会

  • $AMAT（应用材料）财报：@nft_hu（Fiona）拆解——收入、EPS、指引三超预期，但股价下跌，因为「预期拉得太满，财报没给惊喜」。瑕疵：毛利率没继续突破、自由现金流同比降 80%、CAPEX 增加。→ 典型「利好出尽」。
  • $NBIS（Nebius）云合同收费标准（@nft_hu）：1–3 年核心 AI 云合同约 2000 万–2500 万美金/兆瓦，短期专用容量 4000 万–5000 万美金/兆瓦。
  • $AAOI vs $LITE：Serenity 预期 $AAOI 若完全执行产能扩张，有望在 2028 上半年营收逼近甚至（20% 概率）超过 $LITE——当前估值 $12B vs ~$80B，差异主要来自 Lumentum 更好的毛利。
  • $AVGO（博通）当天大跌：@labubu_trader 归因于「杠杆资金此前爆炒、现在无杠杆/少杠杆买入」的筹码结构切换。
  • $IEF 优于 $TLT：@labubu_trader 在被问及利率工具时表示更偏好 $IEF。

⚠️ 免责声明：以上均为博主观点转述，非投资建议。小白请勿照抄，尤其远离杠杆与 2x 工具。

四、市场情绪温度计 🌡️

偏热（结构分化）

  • 🔥 存储/闪迪：情绪炽热，多头狂欢，但川沐自己都承认「赌性上头」——这是情绪过热的典型信号。
  • 😬 AI 芯片财报：$AMAT 三超预期仍跌，说明市场对「超预期」的阈值已经被抬得很高。
  • 🧊 交叉印证：Serenity 晒出经历 7 月 AI 崩盘后 YTD 仍 +2,411.84%，其中 69.2% 是未实现浮盈、98% 纯正股——这既是实力也是警示：极端收益背后是极端波动。
  • 🌐 宏观暗流：@qinbafrank 提到 A 股「国家队从消费/金融/地产老登股系统性撤退」，茅台前十大股东已无国家队——内资风险偏好在变化。

综合：主线清晰但局部过热，适合「看懂方向、别追高、别上杠杆」。

五、给小白的一句话

今天的课就一个字：「长协」。闪迪用 930 亿美金的最低合同收入，把未来四年的「地板」提前锁死了——这就是为什么周期股突然被当成长青资产看。你要学会区分「现在涨得猛」和「未来跌不穿」，前者靠情绪，后者靠合同。别追涨停，去追那些「有合同托底」的东西。

六、专有名词小词典

  • $SNDK / 闪迪：SanDisk，存储芯片公司，本报告核心标的。
  • $MU / 美光：Micron，美国存储芯片巨头。
  • $INTC / 英特尔：Intel，正在研究 CPU+存储堆叠封装。
  • $NVDA / 英伟达：Nvidia，CPO 交换机与 GPU 霸主。
  • $AAPL / 苹果：Apple，被敦促不买中国存储。
  • $AMAT / 应用材料：半导体设备商，本期财报「利好出尽」。
  • $AVGO / 博通：Broadcom，当天大跌。
  • $NBIS / Nebius：AI 云算力公司。
  • $META：Meta，支持闪迪 HBF 标准。
  • $SPY / $QQQ：标普 500 / 纳指 ETF，定投首选。
  • NBM / 长协（LTA）：长期供货协议，锁产能锁价格。
  • floor / ceiling：地板价 / 顶价，长协的可变定价边界。
  • HBM / HBF / DRAM：高带宽存储 / 闪迪高带宽标准 / 动态随机存取内存。
  • CPO（Co-Packaged Optics）：共封装光学，把光引擎和芯片封装在一起，取代可插拔光模块。
  • SoIC：台积电 3D 堆叠封装技术。
  • CSP：Cloud Service Provider，云服务商（此处指 AI 云算力）。
  • 毛利率 / 营业利润率 / FCF：衡量盈利能力的指标；FCF 即自由现金流。
  • EPS / CAPEX：每股收益 / 资本开支。
  • GAAP / 非 GAAP：通用会计准则 / 调整后口径。
  • YTD：Year To Date，年初至今的收益。
  • UAS / Agent / 2x 工具：无人机系统 / AI 代理 / 杠杆 ETF。
