# 美股小白观察报告 · 2026.08.14

## 一、今日最热方向

**存储（NAND/闪存）是今天当之无愧的 C 位。** 闪迪 $SNDK 投资者日放出一套「三年超激进」目标，直接把整个存储板块的情绪点燃。

核心引爆点：
- 闪迪承诺 **完成投资后把 100% 剩余现金返还股东**；
- 给出 2028–2030 财年非 GAAP 口径目标：毛利率约 **80%**、营业利润率约 **75%**、调整后自由现金流利润率约 **50%**；
- 已锁定 **八大客户长期协议**，覆盖 2028 财年约三分之二的比特出货量；
- 两大看点：**NBM 协议**（重塑 NAND 行业商业模式，让周期变平滑）和 **HBF**（介于 HBM 与 SSD 之间的新型存储层级，押注 AI 推理）。

博主反应很真实：川沐直呼「今天真是这个月涨的最舒服的一天，其他几家不能太不要脸吧」，还补了一刀——**$META 成为继谷歌之后第二家共同开发闪迪 HBF 标准的大公司**。qinbafrank 则从产业逻辑解读：闪迪敢给激进指引，本质是想用三年清晰指引把市场对「周期顶部」的恐惧往后推。

⚠️ 但别忘了 qinbafrank 早前的提醒：存储「涨幅最暴力的阶段已经过去」，现在是周期 vs 成长的争议焦点，不是无脑追高的时候。

## 二、其他关注方向

**① CPU 突然成为 AI 的新「卡脖子」环节（qinbafrank 长文）**

美银最新研报把服务器 CPU 2030 年 TAM 从约 1700 亿**上修到 2106 亿美元**（CAGR 约 36%）。核心逻辑链很顺：Agentic AI 普及 → 推理量爆发 → 每个 agent 都需要 CPU 编排数据 → CPU 与 GPU 配比从 1:8 向 **1:1** 靠拢 → CPU 市场规模翻倍。

- $INTC：陈立武个人认购 1200 万美元股票（197 亿增发的一部分），18A 制程首款数据中心 CPU（Clearwater Forest，288 个 E-core）量产爬坡；还在探索 CPU+内存堆叠的新架构。
- $AMD：第 6 代 EPYC Venice 是台积电 2nm 首个量产高性能芯片。
- ARM：自研 AGI CPU 芯片已送样，目标 2026 年底前量产。

川沐从 DeepSeek 新 agent「DSH」的测评里读出了佐证：token 消耗量大、KV 缓存命中率是关键，同任务耗时是 GPT/Claude 的 2 倍——这正是「CPU+DRAM 堆叠封装」路线的底层需求。

**② AI 云算力（CSP/Neocloud）五大趋势（qinbafrank）**

从 $CRWV（CoreWeave）和 $NBIS（Nebius）财报提炼：
1. 需求仍远大于可交付供给——瓶颈已从「有没有客户」变成「什么时候通电、交付 GPU 开始计费」；
2. 定价权增强，但涨价集中在短期容量、新代 GPU、大规模集群，不是无差别上涨；
3. 项目级 ROI 能算过账，但公司级 ROIC 还没证明（折旧+利息仍吞噬利润）；
4. 都在往「AI 基础设施操作系统」升级，不再只是出租一张 GPU；
5. 开始引入第三方资本，Nebius 偏轻资产、CoreWeave Omni 偏混合云/主权 AI。

Fiona 补充了 $NBIS 云合同的具体收费标准：1–3 年核心 AI 云合同约 2000–2500 万美元/兆瓦，3–6 个月专用容量达 4000–5000 万美元/兆瓦以上——涨价确实实打实。

**③ 英伟达 Feynman 平台提前引爆先进封装/CPO（Jukan）**

台湾 DigiTimes 报道：英伟达下一代平台 Feynman 将**跳过 2nm、直接上 A16**（台积电升级版 2nm），并提高 SoIC 3D 堆叠比例，叠加定制 HBM 与 **CPO**。台积电 SoIC 月产能 2027 年底要冲到 5 万片/月。Jukan 特别点出：原计划做 SoIC 的 AP7 P2 可能部分转做 CPO 和 CoWoS——**意味着 CPO 被提前拉动了**。

Macro_Lin 冷静泼了盆水：「先把 Kyber 背板搞定，去往 CPO 的路上不确定性还不少」。

**④ 英特尔 $INTC 获投行力挺（Jukan 转广发证券海外电子）**

增发从 15bn 上调到 20bn，机构需求据报超 100bn，发行价 95 美元，绿鞋全额行使。广发维持「买入」和 **136 美元目标价**，认为增发是积极信号，foundry 业务预计 2027 年底达到盈亏平衡，18A 良率约 80%。

**⑤ 其他零散但值得留意**
- **$AMAT 财报「好但不够好」**（Fiona）：收入、EPS、指引全线超预期，股价却跌——预期拉太满，毛利率没突破、自由现金流同比降 80%、CAPEX 增加。
- **无人机供应链关税**（Serenity）：特朗普签署行政令强化美国无人机供应链，对部分无人机/关键部件征 100% 关税，受益标的 $UMAC、$ONDS、$RCAT。
- **玻璃基板时间表又延后**（Serenity）：三星电机、SKC 的玻璃基板量产时间双双推迟约一个季度，相关玩家 $LPK 等的放量节奏会跟着拖。
- **$COHR（Coherent）财报**：Irrational Analysis 今晚写 Note，qinbafrank 表示相对更看好 $LITE，会做 lite vs cohr 对比分析。
- **DeepSeek Harness 开源**（Star）：Agent = Model + Harness，模型之外皆插件，对 agent 生态是个信号。

## 三、值得关注的单点机会

- **$SNDK**：存储最强叙事，但短期涨幅已大，谨慎的是「利好兑现」风险。
- **$INTC**：CPU 紧缺 + 投行 136 目标价 + CEO 真金白银认购，是当前分歧中偏多的标的。
- **$AMD / ARM**：CPU 主线下的「卖水人」，逻辑最顺、业绩可验证。
- **$NBIS / $CRWV**：AI 云算力涨价是实打实的收入兑现，但估值已高，追的是「项目 ROI 算得过账」这个拐点。
- **$AMAT**：财报不差但股价用脚投票，说明市场对半导体设备的要求已经高到「必须惊喜」，短线不追。
- **$SMCI**：Serenity 在财报日看到指引后亲自买入了——但他自己也调侃「吹风机（负面消息）只能压住股价这么久」，属于高风险博弈。
- **$RDDT**：纳入 S&P 500 的预期在发酵（Serenity 提到）。

## 四、市场情绪温度计 🌡️

**偏暖（中性偏多）** —— 约 65/100。

理由：存储、CPU、AI 算力、先进封装四条主线同时活跃，闪迪的股东回报直接点燃存储情绪，川沐「这个月涨最舒服的一天」是散户情绪回暖的缩影。但 AMAT「好财报跌股价」、玻璃基板时间表延后、以及 qinbafrank 对存储「暴力涨幅阶段已过」的持续提示，都说明**预期已经被拉得很高**，市场处于「看多但要挑着买」的阶段，而非全面普涨。

## 五、给小白的一句话

今天的热点很多，但别被「100% 股东回报」「2x 工具」这类字眼冲昏头——川沐自己都承认「赌性太强，越涨越想上杠杆，得靠定投 $SPY 和 $QQQ 兜底」。**先看懂 CPU 和存储这两条主线背后的产业逻辑，再谈要不要下场，比追着代码跑重要得多。**

## 六、专有名词小词典

- **$TICKER**：美股股票代码，前缀 `$` 表示，如 $NVDA 是英伟达。
- **CSP**：Cloud Service Provider，云服务商；文中泛指提供 AI 云算力的大厂。
- **Neocloud**：新云，专做 GPU 云算力租赁的新兴公司，如 CoreWeave、Nebius。
- **TAM**：Total Addressable Market，可触达的市场总规模。
- **CAGR**：复合年增长率。
- **Agentic AI / Agent**：能自主规划、调用工具完成任务的智能体，是当前 AI 从「聊天」走向「干活」的方向。
- **CPU / GPU 配比**：数据中心里 CPU 与 GPU 的数量比例，从 1:8 向 1:1 靠拢意味着 CPU 需求大增。
- **18A / 2nm / A16**：芯片制程节点，数字越小越先进；18A 是英特尔的 1.8nm 级制程，A16 是台积电 2nm 的升级版。
- **EMIB**：英特尔的一种先进封装技术。
- **SoIC / CoWoS / CPO**：先进封装/互连技术；CPO（Co-Packaged Optics）把光模块直接封装到芯片上，是 AI 算力下一代方向。
- **HBM**：高带宽内存，堆叠在 GPU 旁的高速存储。
- **HBF**：闪迪提出的新型存储层级，介于 HBM 和 SSD 之间，瞄准 AI 推理的带宽+容量需求。
- **NBM 协议**：闪迪推动的长期供货协议模式，旨在平滑 NAND 的行业周期波动。
- **NAND / SSD**：闪存颗粒 / 固态硬盘，是存储板块的核心产品。
- **毛利率 / 营业利润率 / 自由现金流利润率**：衡量公司赚钱能力的三个指标，数值越高通常越好。
- **非 GAAP**：非美国通用会计准则口径，公司常用它来展示「剔除一次性因素」后的经营表现。
- **EPS**：每股收益，衡量公司每股赚多少钱。
- **CAPEX**：资本开支，公司买设备、建厂的投入。
- **ROI / ROIC**：投资回报率 / 投入资本回报率，衡量「投下去的钱赚不赚得回来」。
- **LTA**：长期供货协议（Long-Term Agreement）。
- **UAS**：Unmanned Aircraft System，无人机系统。
- **Harness**：智能体的「执行框架」，模型之外负责理解环境、调用工具的部分。
- **2x 工具 / 杠杆**：放大涨跌幅的金融产品，涨时双倍爽、跌时双倍痛，风险极高。
- **绿鞋（greenshoe）**：增发时允许承销商超额配售的机制。
