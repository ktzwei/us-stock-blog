# 美股小白观察报告 · 2026.08.28

> 今天的主线很清晰：**AI 芯片/算力的权力正在被重新洗牌**。英伟达刹车、ASIC 抢戏、光模块产能被疯抢，三件事其实是同一件事。

---

## 一、今日最热方向

### 🔥 AI 芯片：英伟达「算力换营收」折戟，ASIC 抢跑

**@qinbafrank** 今天把英伟达的一记急刹车讲透了。据华尔街日报，$NVDA 暂停了向 AI 云厂商提供信贷支持、以换取收入分成的交易，两个原因：

1. **内部担忧反垄断审查**——已经大到不敢再「指挥客户怎么做生意」了；
2. **想控制芯片租给谁**：只能租给英伟达认可的客户、容量分散给多家小公司，结果云厂商集体抵制。

他的原话很扎：一家已经大到要小心反垄断的芯片公司，试图用「保底+抽成」去组织下游云市场，两周到两个月内就发现这条线走不通，于是先刹车。**暂停≠终止**，调整条款后大概率继续搞。

**@Macro_Lin** 则从更底层补了一刀：两年前他说 ASIC 没优势的人，现在都闭嘴了。他的判断是——**一旦进入推理跑道，ASIC 会抢走 GPU 差不多一半的市场**。逻辑很硬：竞争维度越来越向 **per token cost（单 token 成本）** 靠拢，这直接决定模型公司的毛利，谁都不想被英伟达在中间剥一层皮。越来越多模型公司下场自研推理芯片，就是这个趋势的注脚。

**@fin** 补上供给端数据：OpenAI 目前约 50% 是 training（训练），推理（inference）之后占比会更大——「太赚钱了」。他的判断：**2027 年算力依然紧缺，2028 年能见度还不好说**。边际定价来自边际需求。

> 一句话串起来：英伟达不敢再「收租」了，客户不想再被「剥皮」了，ASIC 和自研芯片正在瓜分推理这块最肥的肉。

## 二、其他关注方向

### 📡 光模块/CPO 上游：CW 激光产能被疯抢

**@Serenity** 今天的核心标的是 **$SIVE（Sivers）**——一家切入 CW 激光（硅光收发器的关键器件）的公司。他的逻辑：

- 各大云厂商/CSP 都在想尽办法**锁定合格的 CW 激光产能**；
- Sivers 借 Win Semi 的产能入场，手里有 2.5 年现金流（Q2 经营现金流出 + 募资的 $70m），且 bootstrap 转换后**没有有息债务**；
- 他反复拿 **$AAOI（$30 时）、$AEHR（$30 时）** 类比：当年也被市场错杀、被算法+空头+一堆复活账号围攻，现在回头看都是底。

风险他自己也点了：**不看好 Sivers 现在转 hybrid manufacturing**（约占 1/3 产能），认为切换节奏不理想。但整体是「被错杀的资质周期半导体玩家」的判断。

### 🔬 高速光互连细节

**@Irrational Analysis** 很技术流：提到 **DWDM 的 ELSFP 方案在 50% 毛利率下能解决问题（2028 Q1 落地）**，以及「所有需要 HBM 的初创公司」这条链。这是光互连/HBM 上游的细分观察，偏硬核，适合对供应链感兴趣的人盯。

### 🧠 AI Agent 经济：从「会说话」到「能花钱」

**@雨中狂睡** 点了一个关键转变：**提示词够精确时 AI Agent 已经够用，真正的卡点是人类敢不敢给它授权**。他关注 **Talus v2.0**——把 Agent 经济标准化、制度化，后面要盯「多少钱、多少任务、多少 Agent 真正跑起来」。

**@Star** 呼应了同一条线：**Stripe 发布 Link CLI**，让 Agent 能通过 Stripe 付款。流程是用户授权 Link 账户 → Agent 花钱时生成「支出请求」→ 用户用 Face ID/短信 2FA 批准（即将支持预批准预算）。Link 有 3 亿消费者，这更像是把 Agent-to-Agent 交易落地的基建。他还让 Grok 评价自己的投资风格，结果被归到 **Michael Saylor + 段永平** 那一挂。

### ☁️ 软件/SaaS：Salesforce 财报点燃的「AI 收入」叙事

**@qinbafrank** 昨天 Salesforce 强劲财报带动软件和 SaaS 走强，验证他 7 月的判断：**垂直 SaaS 掌握「工作入口 + 业务语义 + 历史数据 + 行业规则 + 动作执行」**，能把模型能力包装成高价值业务结果；而「只给通用模型套个壳」的薄应用，反而容易被模型厂商或 CSP 替代。真正拥有工作流和独家数据的 SaaS 才有护城河。

### 🏛️ 宏观：Fed 的鹰派可以，但别含糊

**@Labubu** 明确表达了对某位（Morgan Stanley 的）观点的异议：**他不在意鹰派，但希望 Fed 在「如何达成通胀目标」上给清楚路径——鹰派可以，不能含糊（no ambiguity）**。这是对降息节奏/通胀路径的谨慎关注。

### ⚠️ 财报前的「护城河」拷问

**@Fiona** 只发了一条，但信息量不小：**「曾经的护城河还依旧稳固么？财报前出这个消息不是太妙——但设计研发不等于批量化生产的能力」**。她在提醒：别把「能设计」当成「能量产」，尤其财报前传出的消息要多留个心眼。

## 六、专有名词小词典

- **$NVDA / 英伟达**：全球 GPU 霸主，AI 算力的「卖铲人」。
- **ASIC**：专用集成电路，为特定任务（如推理）定制芯片，比通用 GPU 更省成本、更省电。
- **per token cost（单 token 成本）**：处理每个 AI 生成片段（token）的成本，是推理经济性的核心指标。
- **training / inference（训练 / 推理）**：训练 = 教模型学习；推理 = 模型实际回答问题。前者烧钱，后者才是持续赚钱的口。
- **CW 激光**：连续波激光，硅光收发器里的关键器件，光模块上游产能。
- **CPO / 光模块**：把光通信器件集成到芯片封装，提升数据中心互连速度。
- **DWDM**：密集波分复用，一根光纤传多路信号的技术，高速互连的核心。
- **ELSFP**：外部激光源小型可插拔器件，一种光互连方案。
- **HBM**：高带宽内存，AI 芯片堆叠内存，供不应求的核心器件。
- **SaaS**：软件即服务，按订阅收费的软件模式。
- **CSP**：云服务提供商（如 AWS、Azure、Google Cloud）。
- **HVM**：高量产（High Volume Manufacturing），从「能做出样品」到「能量产」的分水岭。
- **Fed / 鹰派 / 鸽派**：美联储；鹰派=倾向加息/紧、控制通胀；鸽派=倾向宽松。
- **CSP 控制横向底座 vs 垂直 SaaS**：横向大模型是「底座」，垂直 SaaS 是「业务执行层」，谁掌握入口和行业数据谁更有价值。
