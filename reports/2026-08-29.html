今日主线：沃什（Warsh）全球央行年会讲话 引爆债券市场——短端定价「可能加息」、长端定价「抗通胀来真的」。同时 AI 硬件（光通信/定制芯片/存储）和 AI Agent 经济两条产业线继续升温。11 位博主全部覆盖，一个不少。

一、今日最热方向

🔥 沃什讲话 & 收益率曲线（宏观主线）

今天几乎所有聊宏观的博主都在盯这场讲话。核心结论一句话：沃什偏鹰，但给出了比上次 FOMC 更清晰的「抗通胀」信号。

qinbafrank 复盘得很细，直言「对错各半」： - 对的部分——沃什部分回应市场关切、通胀立场偏鹰、明确保留加息选项但不直接承诺 9 月加息； - 错的部分——整体基调偏鹰而非「不鹰」。 - 落地到收益率曲线：30 年期美债跌、10 年期冲高回落、2 年期上涨。 - 解读：短端在定价「可能要加息了」，长端在定价「他这次是认真的，长期通胀风险没那么可怕」。市场最担心的是通胀控不住。

Labubu 的视角更积极，认为沃什这次比上次 FOMC 清晰得多： - 「如果通胀没有以够快速度回到 2%，就采取行动」这句话本身就是积极信号。 - 判断：收益率曲线将走平（flatten），下周要重点观察债券市场反应； - 如果长端利率下行，CDS 会收窄，可能引发空头回补（short cover）。 - 还点了一句「利好 AMZN/MSFT/GOOG」——长端利率走低对高久期科技股是顺风。

Macro_Lin 只甩了一句定性：「巨大的 pricing regime shift」——定价机制/范式正在切换。

小白翻译：利率曲线「短端涨、长端跌」＝市场觉得短期可能要加息、但长期通胀有救了。这对成长股（科技、AI）偏友好。

二、其他关注方向

💡 AI 硬件：光通信 / 定制芯片 / 存储

Serenity（$SIVE / Sivers 财报深度）： - 批评管理层低估了两个最关键披露：6 个 pluggable 客户 + Foundry 产能（行业瓶颈期）； - 核心逻辑：CSP/大厂正疯狂锁定任何合格的 CW 激光产能（用于光收发模块），Sivers 携 Win Semi 大产能入场； - 用 pipeline revenue 衡量客户质量（举例 $JBL / $GFS Q1 是 $700M+）； - 拿 $AAOI、$AEHR 类比，说「发展合约收入被看空」是老戏码。

Fiona（$MRVL vs $AVGO 毛利率对比，很有料）： - $MRVL FY2027 Q2 GAAP/Non-GAAP 毛利率 53.1% / 58.9%； - $AVGO FY2026 Q2 GAAP/Non-GAAP 毛利率 69.5% / 77.1%； - 两者同属 custom silicon co-design 双寡头，毛利率差距主因在于业务结构。

Jukan（存储 & 算力）： - TrendForce：Vera Rubin 的 ASP 预计是 GB300 的 2 倍，明年 GB300+VR200+VR300 合计产值预计 $7100 亿； - CXMT（长鑫存储）开始量产 LPDDR6。

Irrational Analysis： - 点 AMD 这次没怎么讲 EPYC、FPGA 反而更受关注； - 提到 DWDM ELSFP 若做到 50% 毛利，Q1 2028 能解套；HBM 对初创也是刚需。

🤖 AI Agent 经济 & Token Factory

fin（Token Factory 系列，数据扎实）： - 观点犀利：AI Agent 本质是「人的代理（proxy）」，不存在独立的 agent economy，只是 proxy economy——agent 赚的每一块钱都属于 owner，agent 花的每一分都是成本； - 数据：AWS Bedrock 上季度 ARR 约 $13B，其中 ~80% 是 Anthropic 模型（约 $10B）；Bedrock 占 AWS AI 的 ~55%（~$14B ARR）； - 开源模型在 AWS+Azure 合计给到 ~$1.5B ARR 估计，NV 亲自下场是想加速这个进程； - 硅谷大厂（Apple/NVDA/AMD）$10k/月 token 限额是准的，但 95% 的人远够不到，中位数更低。

雨中狂睡（Talus v2.0）： - 核心卡点不是模型不够好，而是「让人放心给 Agent 授权」； - Talus v2.0 在做的事：把 Agent 经济标准化、制度化；后面盯三个数——多少钱、多少任务、多少 Agent 真正跑起来。

三、值得关注的单点机会

  • $SIVE（Sivers）：Serenity 深度看好，逻辑是「CW 激光产能稀缺 + Win Semi 大产能 + Foundry 瓶颈期」。但注意他批评了管理层披露不到位，属于高波动小盘，小白别重仓。
  • 光通信/定制芯片双寡头（$MRVL / $AVGO）：Fiona 的毛利率拆解给了很干净的对比框架，若 AI 算力 Capex 持续，custom silicon 是核心受益层。
  • 存储链：Jukan 提到的 Vera Rubin ASP 翻倍 + CXMT 量产 LPDDR6，指向明年 AI 存储需求继续爆发（可关注 $MU 及相关 HBM 链）。
  • 化肥链：川沐的厄尔尼诺逻辑，若小麦价格持续走强，磷/钾/氮肥是滞后受益方向（如 $MOS / $NTR / $CF 类）。

四、市场情绪温度计 🌡️

整体：中性偏暖（60/100）

  • 宏观：沃什偏鹰但「抗通胀来真的」给长端松了绑，情绪从紧绷转温和 → 对成长股偏友好；
  • 产业：AI 硬件 + Agent 经济双线热度不减，多家博主在认真拆财报和毛利率，说明市场处于「研究型做多」而非狂热追高；
  • 隐忧：短端利率上行（加息预期）对高估值资产仍是头顶一把剑，基本面弱的资产压力大（qinbafrank 原话）。

五、给小白的一句话

今天最该记住的不是「沃什鹰不鹰」，而是短端和长端利率开始分化——长期通胀被锚定的概率在上升，这对你手里拿着的好公司（尤其 AI/科技）是好事。别被「要加息了」吓到乱动，看懂曲线比看单句新闻重要得多。

六、专有名词小词典

术语 大白话
收益率曲线（yield curve） 不同期限国债利率连成的线，短端涨/长端跌＝市场觉得近期紧、远期稳
曲线走平（flatten） 长短端利差收窄，通常反映「近期利率上行」预期
CSP Cloud Service Provider，云服务商（微软、谷歌、AWS 等）
CW 激光 连续波激光，光模块里的关键光源，产能紧张
pipeline revenue 「管线收入」，衡量客户质量的先行指标，还没落地的预期收入
custom silicon / co-design 定制芯片 / 联合设计，帮大厂设计专用 AI 芯片（$MRVL、$AVGO 核心业务）
ASP Average Selling Price，平均售价
LPDDR6 / HBM 低功耗内存 / 高带宽内存，AI 芯片配套存储
Token Factory fin 自创概念，指「生产/消耗 AI 算力 token」的商业模式
ARR Annual Recurring Revenue，年化经常性收入
CDS 信用违约互换，收窄＝市场认为违约风险下降
空头回补（short cover） 做空的人被迫买回平仓，会推高价格
厄尔尼诺 太平洋海温异常，会引发全球粮食减产/涨价
