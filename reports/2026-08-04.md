# 美股小白观察报告 · 2026.08.04

## 一、今日最热方向

### 🔥 存储/HBM 超级周期确认

今天博主圈几乎被同一条新闻刷屏——**SK 海力士、三星、美光 2027 年 DRAM/HBM 产能已全部售罄**，NAND 也基本清空。这不是小道消息，DigiTimes 正式报道了。

**为什么这事儿炸了？** 几个逻辑在共振：

1. **需求端暴增**：DeepSeek 把百万 token 打到 0.02 人民币，远低于行业 1 美分的底线，倒逼所有大模型降价。用户同样的预算能消耗好几倍的 token → 存储需求指数级上升（@xiaomustock）
2. **供给端卡脖子**：HBM 产能本来就不够，现在连 2027 年的都卖完了。这意味着未来两年的供需格局极度偏紧（@aleaboreddit, @jukan05）
3. **还有新玩家入局**：Google 正式加入 SK 海力士和闪迪主导的 **HBF（高带宽闪存）联盟**，要定义下一代存储连接标准（@jukan05）

**博主操作参考**：川沐 @xiaomustock 今天实盘买入韩股 SK 海力士，成本 156 万韩元。理由很清晰：ADR 规则下 8.4 是最早可公布分红计划的时间点 + 回撤后的好价格 + DeepSeek 效应。

## 二、其他关注方向

### ☁️ 超大 CSP（云厂商）逻辑持续强化

@qinbafrank 延续他 7 月中的长文逻辑：**开源模型崛起正在瓦解闭源垄断，云厂商从"Token 二道贩子"变身为 AI 操作系统**。

核心链条：开源模型降低模型层租金 → 云厂掌握路由权、客户与定价权 → 推理降价激发新需求 → 数据中心高利用率 → 持续算力投资。正循环一旦跑通，超大 CSP 就是 AI 时代的收税人。

### 💡 光互连板块：调整最早，反弹或许也最早

@qinbafrank 指出光互连是整个半导体调整中最早跌、跌最久的板块。5 月中 Bernstein 报告说 CPO 兑现没那么快，今年还是看光模块和连接。近期催化两点：一是 CSP 资本开支继续超预期，二是技术路线之争中传统光模块被重新定价。

### 🌍 地缘政治：海峡危机缓和

特朗普宣布取消对伊朗攻击，双方通过阿曼达成初步协议——开放霍尔木兹海峡 + 结束核计划。@qinbafrank 的解读很直接：**阿曼不可能违抗美国意愿向伊朗低头，所以阿曼与伊朗达成一致 = 美国实质上妥协了**。这对油价和风险资产都是利好信号。

### 🤖 Rubin Ultra HBM 减配争议

NVIDIA 下一代 Rubin Ultra GPU 的 HBM 配置从 12Hi（12 层堆叠）降到 8Hi。市场出现分歧：

- **@fin**：这很可能是 HBM 合约价格谈判期的施压手段——客户集体要求减配来压低明年长约价格
- **@jukan05**：这是供给问题不是需求问题，减配释放的产能反而能造更多 GPU

一个关键风险提示来自 @fin：**如果减配成主流，下一代产品 token 效率还不如上一代，谁还买？**

## 六、专有名词小词典

| 术语 | 解释 |
|------|------|
| **HBM** | High Bandwidth Memory，高带宽内存。AI 芯片（如 NVIDIA GPU）用的高速存储，堆叠多层 DRAM，带宽远超普通内存。当前 HBM3E 是主力，HBM4 在路上 |
| **DRAM** | 动态随机存取存储器，电脑/手机/服务器里的"运行内存"。HBM 是 DRAM 的高端形态 |
| **NAND** | 闪存，SSD 硬盘里用的存储芯片，跟 DRAM 不同，断电不丢数据 |
| **HBF** | High Bandwidth Flash，高带宽闪存。SK 海力士 + 闪迪刚发布的新标准，用 NAND 做高速存储池，可能成为 GPU 和 AI 加速器的新存储层级 |
| **12Hi / 8Hi** | HBM 的堆叠层数。12Hi = 12 层 DRAM 堆叠，容量和带宽更大但良率低、产能少。8Hi 相对成熟但性能弱一些 |
| **CSP** | Cloud Service Provider，云服务提供商。这里主要指 AWS（亚马逊）、Azure（微软）、GCP（谷歌）这三大超大规模云厂商 |
| **CPO** | Co-Packaged Optics，共封装光学。把光模块和芯片封装在一起，技术难度高、量产慢。短期还是传统可插拔光模块的天下 |
| **UCIe** | Universal Chiplet Interconnect Express，通用芯粒互连标准。让不同公司的芯片裸片能拼在一起用的接口协议 |
| **LEAP CALL** | 长期看涨期权，到期日通常超过一年。杠杆大、时间损耗慢，是看好某只股票长期走势时用的工具 |
| **Carry Trade** | 套息交易。借低利率日元投高收益资产。日元一旦快速升值，套息交易者被迫平仓，会引发全球风险资产连锁抛售 |
| **ADR** | American Depositary Receipt，美国存托凭证。外国公司在美国上市的方式。韩国公司（如 SK 海力士）在美国通过 ADR 交易 |
| **Token（AI 语境）** | 大模型处理文本的最小单位，一个 token ≈ 一个英文单词或一个中文字。Token 定价越低，AI 用得越多，算力和存储需求越大 |
