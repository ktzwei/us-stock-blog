### 🧠 半导体：存储市场变局 + SerDes IP 权力转移

两条重磅产业信号同时出现：

1. **长鑫存储（CXMT）LPDDR6 研发接近完成，下半年量产。** 这意味着中国 DRAM 厂商正式进入高端移动内存市场，三巨头（三星、海力士、美光）的份额将被侵蚀。但核心壁垒在 HBM4——英伟达算力链条上，美国不可能把 HBM 交给长鑫封装，所以存储市场的「真正爆发增长点」仍是三巨头的 HBM 业务。（via @jukan05 @xiaomustock）

2. **联发科（MediaTek）448G SerDes IP 追上来。** SerDes（高速串行接口）是承接云厂商 AI ASIC 定制订单的入场券，此前只有 $AVGO Broadcom、$MRVL Marvell 和被高通收购的 Alphawave 三家有顶级 SerDes IP。MTK 的突破意味着 AI ASIC 定制市场可能迎来新玩家。（via @jukan05 @LinQingV）

两条线合在一起看：存储三巨头短期有长鑫冲击的利空叙事，但 HBM 护城河仍在；$AVGO 面临 MTK 在 ASIC 定制领域的潜在竞争。

## 六、专有名词小词典

| 术语 | 解释 |
|------|------|
| **SerDes** | Serializer/Deserializer，高速串行数据接口。AI 芯片之间数据传输的核心技术，谁能做顶级 SerDes IP，谁就能接云厂商的 AI 定制芯片订单 |
| **ASIC** | Application-Specific Integrated Circuit，专用集成电路。云厂商（Google、Amazon、Meta 等）自研的 AI 芯片，找 Broadcom/Marvell 等定制 |
| **HBM** | High Bandwidth Memory，高带宽内存。AI 算力芯片（如英伟达 GPU）必备的高速内存，目前三巨头垄断 |
| **LPDDR6** | Low Power Double Data Rate 6，第六代低功耗内存标准，主要用于手机等移动设备 |
| **FCF** | Free Cash Flow，自由现金流。企业经营真正赚到的钱，扣除维持运营的资本开支后剩下的部分 |
| **Carry Trade** | 套息交易。借低息货币（如日元）投资高收益资产。日元升值时套息交易平仓会引发资产抛售 |
| **DAU** | Daily Active Users，日活跃用户数 |
| **LP** | Limited Partner，有限合伙人，即给 VC/PE 基金出钱的投资方 |
| **HBM4** | HBM 第四代，下一代高带宽内存标准 |
| **DRAM** | Dynamic Random Access Memory，动态随机存取存储器，最常见的内存类型 |
