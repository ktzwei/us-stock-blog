# 美股小白观察报告 · 2026.08.26

## 一、今日最热方向

### 🔥 1. OpenAI 自研芯片 Jalapeño：向英伟达「护城河」开火

今天博主圈讨论度最高的一条主线，是 OpenAI 自研芯片 **Jalapeño** 的实测数据曝光。

- **@qinbafrank**：OpenAI 表示 Jalapeño 在「单位功耗 AI 工作量」和「响应速度」两项指标上均领先英伟达 $GB300；芯片负责人 Richard Ho 称其在 **700 瓦低功耗**下即可实现强劲性能，有助于大幅降低数据中心电力成本。SemiAnalysis 研究人员亲赴实验室用自研基准 InferenceX 实测，结论是 Jalapeño 的 **每瓦性能（perf/W）击败了所有他们测过的英伟达、AMD、谷歌芯片**。
- **@Macro_Lin**：重提两年前的观点——一旦进入**推理（inference）跑道**，ASIC 会抢走 GPU 差不多一半的市场。现在趋势更明显：越来越多模型公司下场做自己的推理芯片，因为竞争维度正转向 **per token cost（每 token 成本）**，这直接决定毛利，没人想被 NV 中间「剥一层」。小米这次发布芯片 + AIPC，也让「大模型端侧部署」叙事升温。
- **@Jukan**：Jalapeño 让他意识到，芯片**设计门槛**正在快速降低，真正的护城河会回到**制造（manufacturing）**环节——至少在有足够强的机器人改变这一点之前。他还提到一个反直觉论点：Jalapeño 可能**利好 Cerebras**，因为它给 Meta、AWS 更大压力去回应 OpenAI，从而更激进地采用 Cerebras。
- **@qinbafrank** 补刀：Jalapeño 单点能力强，但**互联和集群能力**可能照 Blackwell 差一大截，这点值得冷静看待。

> 小白视角：别被「击败英伟达」的标题带节奏。真正的看点不是谁强谁弱，而是「自研芯片」这条线会不会让 $NVDA 的高毛利承压，以及 ASIC（定制芯片）阵营的机会。

### 🔥 2. 光模块 / 光通信：瓶颈变成了「产能」而非「价格」

- **@Serenity**：$SMTC（Semtech）财报里最抓人的一句话是 **「availability currently matters more than pricing」**（当前可得性比价格更重要）。光产品订单近期**没有侵蚀预期**。她还特别引用：「行业原本预测要消耗 **5000 万个**光模块（transceiver），现在听到的数字是 **8000-9000 万个**」——需求大幅上修。
- **@Serenity**：$SIVE（Sivers，激光/光子公司）需求太旺，连 Saxo Japan 都专门把它上架了；Sivers 财报在即 + 计划转板纳斯达克。
- **@Fiona**：$MRVL（迈威尔）三条主线：① 谷歌 122 亿美元 warrant + 1200 亿 ASIC 订单绑定；② 与 AWS 5 年多代协议（定制 AI、光 DSP、AEC、DCI 光模块、以太交换芯片）；③ 英伟达老黄曾说 Marvell 会是下一家市值 1 万亿美元的公司。但她提醒：**「曾经的护城河还依旧稳固么？财报前出这个消息不是太妙」**——设计研发 ≠ 批量化生产能力。
- **@川沐**：谷歌 122 亿入股 $MRVL，绑定 1200 亿 ASIC 芯片订单。

> 小白视角：光通信这条链（$SMTC、$MRVL、$SIVE、$COHR 等）是今天真正的「订单上修」方向。核心逻辑是 AI 数据中心对光模块需求被大幅上调，且短期产能紧、价格稳。

### 🔥 3. 存储（Memory）：AI 进化的隐形瓶颈

- **@Jukan**：DigiTimes 消息，YMTC（长江存储）、CXMT（长鑫存储）正寻求提高**供应海外的存储份额**——YMTC 把 NAND 芯片卖给第三方模组厂，由他们组装后出海。
- **@川沐**：真正能解决美债死结的，是美政府孤注一掷用 AI 把社会生产效率拉爆；而 AI 想搞起来就离不开**存储**。潘健成、黄仁勋等大佬都说「真正制约 AI 进化的瓶颈就是存储」——闭环了，美政府想解美债就得把存储拉起来。
- **@川沐**：海力士的「50% 现金回报股东」其实相当于美光、闪迪的 100% 回报，因为海力士折价，同样 50% 的钱能买到一样多的股票。

> 小白视角：存储（$MU 美光、海力士、三星）是 AI 硬件里常被忽略的「刚需」环节。今天博主把存储和「美债 → AI → 存储」串成了一条叙事链。

### 🌡️ 4. 美伊博弈出现「拐点」+ 美债收益率见顶迹象

- **@qinbafrank**：美伊关于霍尔木兹海峡的博弈出现**拐点性时刻**。伊朗开始「选择性放行」——奖励友好国家、分化美国制裁联盟，把全面封锁改成「可随时拧紧或放松的水龙头」。同时美伊缓和 + 贝森特释放**国债回购**信息，长债收益率短期有见顶迹象。油价回落会直接压低通胀预期。
- **@川沐**：美债影响太大，资金缺乏避险渠道。他认为如果未来是美债避险需求引发的上涨，**BTC 涨幅大概率超过黄金**——因为黄金大陆持有量大、拉黄金等于给大陆接盘，而 BTC 基本是美方持有。他列出三条红线：50 万亿美债、10 年期国债利率、以及（美联储是否下场介入）。

> 小白视角：地缘（美伊）+ 美债收益率是今天影响大盘情绪的两大宏观变量。油价、长债利率若回落，对成长股和风险资产都是暖风。

## 六、专有名词小词典

| 术语 | 解释 |
|------|------|
| **ASIC** | 专用集成电路，为特定任务（如 AI 推理）定制的芯片，相比通用 GPU 更省电、单位成本更低 |
| **per token cost** | 每处理一个 token（文字/计算单位）的成本，AI 模型公司最关心的毛利指标 |
| **perf/W（每瓦性能）** | 每瓦电功耗能带来的算力，衡量芯片能效的核心指标 |
| **推理（Inference）** | 训练好的 AI 模型实际运行、输出答案的过程（相对「训练」而言） |
| **光模块（transceiver）** | 数据中心里负责光电转换、高速传输数据的器件，AI 算力扩张的刚需 |
| **warrant** | 认股权证，一种允许在未来以约定价格买入公司股票的金融工具 |
| **长债收益率** | 长期国债（如 10 年期）的到期收益率，反映市场对通胀和利率的预期 |
| **国债回购** | 政府买回已发行的国债，可降低市场供给、压低收益率 |
| **TSV** | Through-Silicon Via，硅通孔，芯片垂直互连的供电/通信技术 |
| **DCA** | Dollar Cost Averaging，定投，定期定额买入以摊平成本 |
| **对数股价图（log chart）** | 纵轴用对数刻度，能更清楚地看出长期倍数的涨幅 |
